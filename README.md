# The Tome Of Boundless Knowledge
A voice recognition E-paper spell tome and reference book for things such as dnd.
<br>The Tome will listen for a wake word followed by a category of spell, at which point it lists all spells in that category. When one is spoken, it will display it.
<br>I wanted to make this as an easier way to manage spells and other data for these scenerios, and plan to expand it's database past spells in the future and provide alternate firmware for purposes such as just using it as an e-reader.
